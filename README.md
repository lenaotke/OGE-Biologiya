# OGE Biologiya

Банк заданий ФИПИ для подготовки к ОГЭ-2027 по биологии: 1979 заданий, все с решениями. Устроен так же, как сайт OGE-Matematika.

- Часть 1 (№1–21): ответ к каждому заданию проверен в открытом банке ФИПИ кнопкой «Ответить». Исключение — 00046B: на ФИПИ ключ этого задания неисправен, ответ дан по учебнику, в карточке есть пометка.
- Часть 2 (№22–26): эталонные ответы по элементам критериев, расчёты перепроверены. Автопроверки этой части на ФИПИ нет.

## Файлы и публикация

- `site.zip` — сайт целиком: `index.html`, `app.js`, `answers.js`, `styles.css`, `bio.css`, `manifest.json`, `search.json`, папки `pages/` и `assets/`.
- `.github/workflows/pages.yml` распаковывает `site.zip` и публикует сайт через GitHub Pages.

Чтобы посмотреть сайт локально, распакуйте `site.zip`, запустите в этой папке `python -m http.server 8000` и откройте http://localhost:8000/.
